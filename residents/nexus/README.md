journal read path for its own memory, and the SAME validator module as
every other seat (AA11 enforced in code). Model artifact: the checkpoint
holding the Nexus seat (currently Run 25), behind a checkpoint-agnostic
interface so a passing run swaps in under replace-only-if-better.

genesis-genome.json is a STANDARD genesis genome (neutral defaults). The
proposed tie-in — deriving it from the owner's cognitive scaffolding — is
an open owner ruling; if approved, the mapping is applied from a private
owner-side file and never committed here in named form.
