# AT-06 — Hidden information

Status: **NOT-YET-DEMONSTRATED** (Kimi's S1 ruling, 2026-11-16; adopted by Muse).

The engine's observation visibility is currently uniform — every resident
perceives the same world facts — until the island map / visibility system
lands. Under uniform visibility an AT-06 suite could only pass vacuously,
and a vacuous pass is a false signal. This suite is therefore deferred,
not green: it runs for real the moment per-resident visibility exists,
and its first run must include a case where a resident demonstrably
cannot perceive a fact another resident can.
